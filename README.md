🐍 Snake Game using Python & Pygame

A classic Snake Game built using Python and the Pygame library.
This project demonstrates basic game development concepts such as game loops, collision detection, keyboard handling, scoring system, and rendering graphics on the screen.

📌 Features

🎮 Smooth snake movement using keyboard arrow keys

🍎 Random food generation

📈 Score tracking system

💀 Game Over detection (wall & self-collision)

🔁 Restart game by pressing ENTER

⏱️ Optimized FPS for smooth gameplay

🎯 How the Game Works

The snake starts at a fixed position.

Use arrow keys to control the snake’s direction.

Eat the red food block to increase your score.

Each food eaten increases the snake’s length.

The game ends if:

The snake hits the wall

The snake collides with itself

Press ENTER to restart after Game Over.
